รหัส DEF ตรงกับชีต Defect Log ในไฟล์ Excel

## P0 — ต้องแก้ก่อนส่งมอบ

### DEF-020 สร้างโปรเจกต์จากเทมเพลตไม่ได้ (Frontend)
- ขั้นตอน: เทมเพลต → "ใช้เทมเพลต" → ถัดไปที่ขั้นประเภทงาน
- Error: `validation_error: Template creation requires an Idempotency-Key of 1-200 characters`
- สาเหตุ: `src/pages/NewProject.tsx:136-140` ส่ง `template_id` ผ่าน `createProject` โดยไม่แนบ header `Idempotency-Key`
- แก้: ให้ `createProject` รับ `idempotencyKey` (แบบ `startTraining` ใน `src/api/endpoints/trainings.ts`) แล้วสร้าง key หนึ่งครั้งต่อการเปิด wizard ด้วย `crypto.randomUUID()` ใช้ key เดิมเมื่อ retry
- ตรวจ: เทมเพลต Thai Sentiment Analyzer สร้างโปรเจกต์ได้ (UAT-TMPL-006)

### DEF-014 ดาวน์โหลดไฟล์โมเดลไม่ได้ (DevOps)
- `GET /api/v1/models/{id}/download-url?format=gguf|lora` ตอบ 503 พร้อมข้อความ `MINIO_PUBLIC_URL is not set — cannot mint presigned download URLs on this deployment`
- แก้: ตั้ง env `MINIO_PUBLIC_URL` ให้ slm-api บน gx10 ให้เป็น URL ที่เบราว์เซอร์เข้าถึงได้ (ผ่าน ngrok/nginx) แล้ว restart
- ตรวจ: ดาวน์โหลด GGUF, LoRA และ README ได้ (UAT-MOD-007)

### DEF-010 ดาวน์โหลดชุดข้อมูลแล้วไม่มีไฟล์ (Backend/Frontend)
- `download-url` ตอบ 503 (สาเหตุเดียวกับ DEF-014) แล้ว fallback `/datasets/{id}/download` ตอบ 200 แต่ไม่มีไฟล์และไม่มีข้อความแจ้ง
- แก้: แก้ DEF-014 ก่อน แล้วตรวจ fallback ว่าสร้างไฟล์ให้ดาวน์โหลดจริง ถ้าล้มเหลวต้องแสดง error
- ตรวจ: UAT-DATA-005 (ทดสอบด้วยมือ)

### DEF-002 หน้าล็อกอินไม่มีลิงก์ลืมรหัสผ่าน (Keycloak)
- ตั้งค่า SMTP ของ realm `tunelab` และเปิด `resetPasswordAllowed` ผ่าน kcadm หรือ admin console (การ import realm ถูกข้ามเพราะ realm มีอยู่แล้ว)
- ตรวจ: UAT-AUTH-009
