Node 3a — Add Seed Data (Upload)

POST multipart/form-data /api/v1/datasets/upload-seed

วัตถุประสงค์

Upload ไฟล์ seed (.jsonl / .json / .pdf) เพื่อใช้เป็น few-shot example ใน SDG. ระบบจะ:

  1. Parse + validate ทุก row ตาม schema ของ task_type
  2. Run Format Detection (Gemini-based) ถ้า keys ไม่ canonical → auto-rename ให้ตรง schema
  3. Persist เป็น Dataset row กับ source=seed

Prerequisite

  • มี project_id จาก Node 1
  • เตรียม seed file ตาม schema ของ task_type (ดูตารางด้านล่าง)

Schema ของแต่ละ task_type

TaskRequired keys ต่อ rowตัวอย่าง
classificationtext, label{"text": "I can't log in", "label": "technical"}
tool_callingquestion, answer (JSON-encoded){"question": "Set oven to 250C", "answer": "{\"name\":\"set_oven\",\"parameters\":{\"celsius\":250}}"}
qaquestion, answer{"question": "Capital of France?", "answer": "Paris"}
ถ้าไฟล์ใช้ key อื่น เช่น message/category แทน text/label — Format Detection จะ rename ให้อัตโนมัติแล้วรายงานใน format_detection.field_mapping

ขั้นตอนใน Swagger UI

  1. เปิด POST /api/v1/datasets/upload-seed
  2. กด Try it out
  3. กรอก form (ดูตัวอย่างต่อ task_type ด้านล่าง)
  4. กด Execute
  5. เก็บ dataset_id — จะใช้เป็น seed_dataset_id ใน Node 4

422schema mismatch ที่ Format Detection แก้ไม่ไหว
422classification labels average N characters (threshold: 30). ...Did you upload a QA file by mistake? — semantic guard: เนื้อหา label ดูเหมือน free-text ไม่ใช่ category สั้นๆ
422classification expects a closed label set, but N/M rows have unique 'label' values (ratio=X, threshold: 0.5)... — semantic guard: labels ไม่ใช่ closed set (อาจเป็น QA file ที่ Format Detection rename มาผิด)
Semantic guard (cls เท่านั้น): หลังจาก Format Detection rename keys แล้ว ระบบจะเช็คเพิ่มสำหรับ classification ว่า labels ดูเป็น closed set จริงไหม — avg ความยาว ≤ 30 chars และ unique_ratio ≤ 0.5 (เมื่อ ≥10 rows). ถ้าไม่ผ่าน → 422 พร้อมข้อความเตือนชัดเจน. ผลคือ: อัปโหลด qa_canonical.jsonl เข้า classification project จะถูก reject ตรงนี้แทนที่จะปล่อยเข้าระบบ. tool_calling validation อยู่ที่ Pydantic ToolCallingSample.answer อยู่แล้ว; qa ไม่มี closed set ให้ enforce
