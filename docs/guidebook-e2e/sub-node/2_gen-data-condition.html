Node 2 — gen data condition (Decision)

DECISION (ไม่มี endpoint — เป็นจุดตัดสินใจ)

วัตถุประสงค์

เลือกว่า project นี้จะ generate synthetic data โดย:

🅰️ With Seed

มี seed data จริงอยู่แล้ว (JSONL / JSON / PDF) → upload ขึ้นระบบก่อน แล้ว SDG ใช้เป็น few-shot example

เหมาะกับ: เคยมี dataset ของจริงอยู่บ้าง, อยากให้ output มี style/domain ตรงกับของจริง

→ ไป Node 3a (upload seed) แล้วต่อ Node 4 ด้วย sdg_mode=with_seed

🅱️ Description Only

ไม่มี seed — มีแต่คำอธิบาย task + labels/tool definitions → ระบบ generate จากศูนย์

เหมาะกับ: เริ่มจากศูนย์, prototype, อยากลอง task type ก่อนหาข้อมูลจริง

→ ข้าม 3a ไป Node 3b (description_only request)
