Node 7 — Export GGUF + Register Ollama

POST ASYNC 202 /api/v1/models/{id}/export
GET /api/v1/models/{id}   ·   GET /api/v1/models/{id}/download

วัตถุประสงค์

Convert LoRA adapter ที่ได้จาก Node 6 → GGUF (q4_k_m) + auto-register กับ Ollama → พร้อมให้ Node 8 (inference) เรียกใช้.

Pipeline ภายใน worker

  1. Load LoRA adapter จาก MinIO
  2. save_pretrained_merged — รวม adapter เข้า base weights (HF f16)
  3. llama.cpp/convert_hf_to_gguf.py → GGUF f16
  4. llama-quantize → q4_k_m (~770 MB สำหรับ 1B base)
  5. Upload GGUF → MinIO (s3://models/exports/{id}/gguf)
  6. Stream blob → Ollama (POST /api/blobs/sha256:<hex>)
  7. Register tag (POST /api/create with files mapping)
  8. (best-effort) ollama pull base equivalent ตาม base_ollama_tag เพื่อ A/B compare ใน Node 8

Prerequisite

  • model_artifact_id จาก Node 6 (training สำเร็จแล้ว)
  • Worker image มี llama.cpp pre-built (llama-quantize + convert_hf_to_gguf.py)
  • Ollama container ขึ้น + reachable จาก worker

Request — GGUF (default recommended)

{
  "format": "gguf",
  "quantization": "q4_k_m"
}

Request — SafeTensors (เก็บ checkpoint ดิบ)

{
  "format": "safetensors"
}

Response 202

{
  "artifact_id": "<uuid>",
  "format": "gguf",
  "job_id": "<celery_uuid>",
  "status": "pending",
  "websocket_url": "/ws/jobs/<celery_uuid>"
}

WebSocket — ไม่มี per-step progress

Export ไม่ส่ง progress event ระหว่างทำ — รอ completed หรือ failed เลย (~90s สำหรับ 1B base บน 3060)

Sample completed

{
  "type": "completed",
  "result": {
    "artifact_id": "<uuid>",
    "format": "gguf",
    "gguf_uri": "s3://models/exports/<artifact_id>/gguf",
    "safetensors_uri": null,
    "ollama_model_tag": "slm/cdeddfd5"
  }
}

Verify post-export

GET /api/v1/models/{artifact_id}
{
  "id": "...",
  "gguf_uri": "s3://models/exports/.../gguf",
  "safetensors_uri": null,
  "size_mb": 770.2,
  "ollama_model_tag": "slm/cdeddfd5",        ← populate แล้ว
  "export_error_message": null,
  "base_ollama_tag": "llama3.2:1b"           ← derived (จาก base_model)
}
เก็บค่าไว้:
  • ollama_model_tag — fine-tuned model (เช่น slm/cdeddfd5)
  • base_ollama_tag — base model สำหรับ A/B compare

(Optional) Download binary

GET /api/v1/models/{id}/download
Content-Type: application/octet-stream
(~770 MB GGUF q4_k_m / ~800MB-1.5GB SafeTensors)

Error cases

SymptomNote
export_error_message != nullworker เขียน error message ไว้ที่ row — อ่านได้จาก GET /models/{id}
ollama_model_tag = null แต่ gguf_uri populateGGUF สำเร็จแต่ Ollama register fail (best-effort) — ใช้ GGUF จาก MinIO ได้

หมายเหตุ: base_ollama_tag = null = base model ตัวนี้ไม่มี Ollama-Hub mapping (rare) → ซ่อนปุ่ม A/B compare ใน FE
