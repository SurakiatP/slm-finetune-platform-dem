Node 1 — Create Project

POST /api/v1/projects

วัตถุประสงค์

สร้าง project ตัวใหม่ — เป็น container สำหรับ datasets / trainings / artifacts ทั้งหมดที่จะตามมา. task_type ที่เลือกตอนนี้จะถูก locked สำหรับทุก resource ใน project นี้ (ห้ามใช้ classification dataset สร้าง qa training).

Prerequisite

  • API ขึ้น (ทดสอบ GET /health → {"status":"ok"})
  • เลือก task_type มาแล้ว: classification / tool_calling / qa

ขั้นตอนใน Swagger UI

  1. เปิด http://<host>:8000/docs
  2. หา section Projects → POST /api/v1/projects
  3. กด Try it out
  4. วาง request body ด้านล่าง → กด Execute
  5. เก็บ id จาก response — จะใช้เป็น project_id ในทุก node ถัดไป

Request body — 3 ตัวอย่าง (ตรงกับ seed_data/)

🅰️ Classification — Thai customer support

Seed file: seed_data/classification/classification_canonical.jsonl (40 rows, 3 labels: ปัญหาการเงิน, ปัญหาเทคนิค, คำถามทั่วไป)

{
  "name": "thai-support-cls",
  "description": "Classify Thai customer support tickets into 3 categories",
  "task_type": "classification"
}

FieldTypeRequiredNote
namestring✓display name (unique ไม่บังคับ)
descriptionstring—คำอธิบาย
task_typeenum✓classification | tool_calling | qa — เลือกอย่างเดียวต่อ project
เลือก task_type ครั้งเดียวต่อ project — จะ locked ในทุก resource (dataset / training / artifact) ใต้ project นี้. ถ้าอยาก test ครบทั้ง 3 task → สร้าง 3 projects แยกกัน
