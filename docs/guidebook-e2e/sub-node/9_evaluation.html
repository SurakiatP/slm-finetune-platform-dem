Node 9 — Evaluation (Rule-based)

POST ASYNC 202 /api/v1/evaluations
GET /api/v1/evaluations   ·   GET /api/v1/evaluations/{id}   ·   POST /api/v1/evaluations/compare

วัตถุประสงค์

วัด quantitative metrics ของ fine-tuned model บน holdout dataset (leak-free) ด้วย rule-based metrics — ไม่ใช้ LLM judge (ฟรี + เร็ว).

Metrics ที่ออกแยกตาม task_type

TaskMetricsSmoke run คาดหวัง (1 epoch, ~30 train rows)Proper run คาดหวัง (3 epochs, 200+ rows)
qableu, rouge1, rouge2, rougeL, exact_match, nrouge1 ~0.15-0.30, judge ~3.0-4.0rouge1 > 0.40, judge > 4.0
classificationaccuracy, f1_macro, f1_per_label (dict), confusion_matrix, naccuracy 0.0-0.4 (model ยังไม่จำ label)accuracy > 0.85
tool_callingjson_validity, name_accuracy, arg_accuracy, exact_match, njson_validity 0.5-0.9, name_accuracy 0-0.4json_validity > 0.95, name_accuracy > 0.85
ทำไม smoke run accuracy ต่ำ: 30 train rows + 1 epoch ไม่พอให้ model 1B จำ label vocabulary ได้ (ถูกพิสูจน์ใน Session 21 — cls accuracy=0.0, tool name_accuracy=0.0). แต่ pipeline ทำงาน. proper accuracy ต้องการ ≥200 rows + 3 epochs.

Prerequisite

  • model_artifact_id จาก Node 6 + ผ่าน Node 7 (มี ollama_model_tag populate)
  • holdout_dataset_id จาก Node 4 — ห้ามใช้ parent (data leak!)
  • Dataset task_type ต้องตรงกับ artifact task_type

Error cases

StatusDetail
404Model <id> not found
409Model has not been registered with Ollama — ลืม export ที่ Node 7
409Dataset has no rows persisted yet — SDG ยังไม่จบหรือ fail
400Dataset task_type=classification does not match artifact task_type=qa
Leak-free rule: ใช้ holdout_dataset_id เท่านั้น — ไม่ใช่ parent. ถ้าใช้ parent → score จะสูงเกินจริง (model เห็น rows เหล่านี้ตอน train)

List evaluations

GET /api/v1/evaluations?model_artifact_id=<uuid>&status=completed

List eval runs (paginated, sort created_at DESC). Filters ทั้งหมด optional — รวมกันได้:

QueryTypeDefaultNote
model_artifact_idUUID—filter เฉพาะ eval ของ model ตัวนี้ (model history)
dataset_idUUID—filter เฉพาะ eval ที่รันบน dataset ตัวนี้ (per-dataset leaderboard)
statusenum—pending / running / completed / failed / cancelled
limitint 1–20050
offsetint ≥00

Response 200 — Page[EvaluationResponse]:

{
  "items": [
    {
      "id": "...",
      "model_artifact_id": "...",
      "dataset_id": "...",
      "status": "completed",
      "metrics_json": { "bleu": 0.02, "rouge1": 0.286, "n": 10 },
      "llm_judge_score": 4.6,
      "llm_judge_model": "google/gemini-3.1-flash-lite-preview"
    }
  ],
  "total": 12,
  "limit": 50,
  "offset": 0
}
FE pattern:
  • หน้า model detail (playground) — ?model_artifact_id=<id> ดึงประวัติ eval ทั้งหมดของ model นั้นมาเรนเดอร์เป็นตาราง
  • หน้า leaderboard per dataset — ?dataset_id=<id>&status=completed
  • polling รายการ pending/running — ?status=running + refetch ทุก ~5s (แทน WS ถ้าไม่อยากเปิด socket เยอะ)
  • FE branch render metrics_json ตาม key (ดูตาราง Metrics ที่ออกแยกตาม task_type ด้านบน) — ไม่ต้องเรียก /datasets/{id} เพิ่มเพื่อหา task_type
