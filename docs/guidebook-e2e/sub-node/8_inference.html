Node 8 — Serve / Inference

GET /api/v1/inference/models
POST /api/v1/inference/chat/completions   ·   POST /api/v1/inference/completions (legacy)

วัตถุประสงค์

ทดสอบ inference จริงกับ fine-tuned model ผ่าน OpenAI-compatible API (proxy ไป Ollama)

Prerequisite

  • ollama_model_tag จาก Node 7 populate แล้ว (เช่น slm/cdeddfd5)
  • Ollama container reachable

8.1 List Ollama models (verify)

GET /api/v1/inference/models

Response (OpenAI-shape):

{
  "object": "list",
  "data": [
    { "id": "slm/cdeddfd5:latest", "object": "model", "created": 0, "owned_by": "ollama" },
    { "id": "llama3.2:1b",          "object": "model", "created": 0, "owned_by": "ollama" }
  ]
}
ถ้า Ollama ว่าง → data: [] (200, ไม่ใช่ 500)

8.2 Chat completion (OpenAI Chat API)

Request (generic)

{
  "model": "<artifact_id หรือ slm/<id8>>",
  "messages": [
    { "role": "system", "content": "You are a helpful assistant." },
    { "role": "user",   "content": "What is the capital of France?" }
  ],
  "max_tokens": 50,
  "temperature": 0.0,
  "stream": false
}

ตัวอย่าง prompt ต่อ task (ตรงกับ seed_data)

🅰️ Classification — Thai support ticket

{
  "model": "<slm/<id8> ของ cls run>",
  "messages": [
    { "role": "user", "content": "แอปบนมือถือ Android เปิดแล้วเด้งออกทันทีหลังหน้า splash" }
  ],
  "max_tokens": 30,
  "temperature": 0.0
}

คาดหวัง output: ปัญหาเทคนิค (1 ใน 3 labels)

🅱️ QA — Thai return policy

{
  "model": "<slm/<id8> ของ qa run>",
  "messages": [
    { "role": "user", "content": "ระยะเวลาในการคืนสินค้าเท่าไรคะ?" }
  ],
  "max_tokens": 150,
  "temperature": 0.2
}

คาดหวัง output: ประมาณ "ลูกค้าสามารถคืนสินค้าได้ภายใน 30 วัน..."

🅲 Tool Calling — Smart home

{
  "model": "<slm/<id8> ของ tool run>",
  "messages": [
    { "role": "user", "content": "Turn on the kitchen lights" }
  ],
  "max_tokens": 80,
  "temperature": 0.0
}

คาดหวัง output: {"name":"light_on","parameters":{"room":"kitchen"}} (JSON string)

Tool calling output ต้องเป็น JSON เท่านั้น — ถ้า model พ่นข้อความตามปกติออกมา (เช่น "Sure, turning on...") แปลว่า fine-tune ไม่พอ → เพิ่ม num_train_epochs หรือ num_samples
model รับทั้ง 2 รูปแบบ: artifact UUID หรือ Ollama tag — service resolve ให้เอง

8.3 Legacy completion (OpenAI Completions API)

สำหรับ tools เก่าที่ยังใช้ prompt แทน messages

POST /api/v1/inference/completions
{
  "model": "<artifact_id>",
  "prompt": "The capital of France is",
  "max_tokens": 20,
  "temperature": 0.0
}

Response — note: choices[].text (ไม่ใช่ choices[].message.content)

{
  "id": "cmpl-940",
  "choices": [
    { "index": 0, "text": " Paris.", "finish_reason": "stop" }
  ],
  "usage": { "prompt_tokens": 15, "completion_tokens": 3, "total_tokens": 18 }
}

A/B Compare (fine-tuned vs base)

เรียก 2 requests พร้อมกัน — model หนึ่งใช้ ollama_model_tag, อีกตัวใช้ base_ollama_tag:

POST /inference/chat/completions  { "model": "llama3.2:1b",   "messages": [...] }  ← base
POST /inference/chat/completions  { "model": "slm/cdeddfd5",  "messages": [...] }  ← fine-tuned

Caveats

เรื่องNote
Streamingยังไม่รองรับ — stream: true จะได้ 400
First request หลัง pull~3-5 วิ (Ollama load model ลง VRAM), subsequent ~0.5-2 วิ
ConcurrencyOllama default = serial per model — ตั้ง OLLAMA_NUM_PARALLEL=2 ถ้าอยากเร็ว (VRAM × 2)

Error cases

StatusDetail
404model id/tag ไม่อยู่ใน Ollama
400stream: true ส่งมา
500Ollama container down (ตรวจ docker compose ps ollama)
