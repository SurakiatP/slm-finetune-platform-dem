Node 3b — Description Only (no seed)

POST ASYNC 202 /api/v1/datasets/generate

วัตถุประสงค์

Trigger SDG โดยไม่มี seed — ใช้แค่ task_description + per-task config (labels หรือ tool_definitions) เป็น input ให้ LLM generate ใหม่ทั้งหมด.

Node 3b นี้คือ "ทางเลือก" ของ Node 3a — ถ้าใช้ description-only ก็ ไม่ต้อง upload seed (Node 3a). request นี้เองคือ Node 4 ในกรณีนี้ — ดูรายละเอียด holdout / async flow ที่ Node 4 ด้วย.

Prerequisite

  • มี project_id จาก Node 1
  • เตรียม task_description (≥10 chars) ที่อธิบาย task ชัดเจน
  • เตรียม config ของ task type ที่เลือก (ดูตัวอย่างด้านล่าง)
ตัวอย่างด้านล่างใช้ domain เดียวกันกับ seed_data/ เพื่อให้เปรียบเทียบผลกับ with_seed (Node 3a) ได้สะดวก

Request — Classification (Thai customer support)

ใช้ labels 3 ตัวที่ตรงกับ seed_data/classification/ ทุกประการ

{
  "sdg_mode": "description_only",
  "project_id": "<uuid จาก Node 1>",
  "task_type": "classification",
  "task_description": "Classify Thai customer support tickets into 3 categories: financial issues, technical issues, or general questions. Tickets are written in informal Thai with polite particles.",
  "num_samples": 20,
  "temperature": 0.8,
  "dataset_name": "cls-desc-only-1",
  "classification_config": {
    "labels": ["ปัญหาการเงิน", "ปัญหาเทคนิค", "คำถามทั่วไป"]
  },
  "holdout_size": 10
}

Request — QA (Thai return policy)

Domain ตรงกับ seed_data/qa/qa_canonical.jsonl

{
  "sdg_mode": "description_only",
  "project_id": "<uuid จาก Node 1>",
  "task_type": "qa",
  "task_description": "ตอบคำถามเกี่ยวกับนโยบายคืนสินค้าและขั้นตอนคืนเงินของร้านค้าออนไลน์ ครอบคลุมระยะเวลาคืน เงื่อนไข ค่าจัดส่งคืน และเอกสารที่ต้องเตรียม",
  "num_samples": 20,
  "dataset_name": "qa-desc-only-1",
  "holdout_size": 10
}

Response 202

{
  "dataset_id": "<uuid>",
  "job_id": "<celery_task_uuid>",
  "status": "pending",
  "websocket_url": "/ws/jobs/<celery_task_uuid>"
}
เก็บค่าไว้: dataset_id, job_id — ใช้ subscribe WS ที่ Node 4

Optional fields ที่ใช้บ่อย

FieldDefaultNote
temperature0.8creativity (0.0-2.0)
holdout_size100over-generate +N rows → split เป็น holdout child dataset (0 = ปิด)
num_samples—1-1000 — train rows ที่ต้องการ

Error cases (422)

  • body.classification_config: Field required — ลืม labels สำหรับ classification
  • body.tool_calling_config: Field required — ลืม tool_definitions
  • task_description: String should have at least 10 characters
