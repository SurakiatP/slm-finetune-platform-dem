Node 6 — Training (Manual / HPO)

POST ASYNC 202 /api/v1/trainings
WS /ws/jobs/{job_id}
DELETE /api/v1/trainings/{id} (cancel — idempotent)

วัตถุประสงค์

Fine-tune base model ≤3B ด้วย QLoRA + Unsloth บน train dataset จาก Node 4. มี 2 modes:

  • Manual — กำหนด hyperparameters เอง (ใช้เมื่อรู้ค่าที่ดีแล้ว)
  • HPO — Optuna search หลาย trials (ใช้เมื่อยังหา hyperparameters ไม่เจอ)

Prerequisite

  • project_id (Node 1) + train_dataset_id (Node 4, parent — ไม่ใช่ holdout child)
  • ตรวจ base model ที่อนุญาต: GET /api/v1/base-models (11 ตัว, ทั้งหมด ≤3B + bnb-4bit)
  • GPU พร้อม + worker container ขึ้น
ใช้ parent dataset เท่านั้น — ห้ามใช้ holdout_dataset_id มาเทรน (ถ้าเทรนกับ holdout → leak ทันที, Node 9 จะวัดผลไม่ได้)

Base model แนะนำต่อ task (จาก seed_data)

Mode 1 — Manual

Request (QA example — ใช้ Llama-3.2-1B 1 epoch สำหรับ smoke test)

{
  "mode": "manual",
  "project_id": "<uuid>",
  "dataset_id": "<train_dataset_id จาก Node 4 (parent)>",
  "base_model": "unsloth/Llama-3.2-1B-Instruct-bnb-4bit",
  "training_name": "qa-smoke",
  "manual_config": {
    "num_train_epochs": 1,
    "per_device_train_batch_size": 2,
    "gradient_accumulation_steps": 8,
    "learning_rate": 2e-4,
    "max_seq_length": 2048,
    "optim": "adamw_8bit",
    "packing": false,
    "lora": {
      "r": 16,
      "alpha": 32,
      "dropout": 0.05,
      "target_modules": ["q_proj","k_proj","v_proj","o_proj","gate_proj","up_proj","down_proj"]
    }
  }
}
Smoke vs proper run:
  • num_train_epochs=1 + num_samples=30 → smoke test เร็ว (~1-2 นาที บน 3090/4090) แต่ accuracy ต่ำ — ใช้พิสูจน์ pipeline ทำงาน
  • num_train_epochs=3 + num_samples=200+ → ผล accuracy จริงสำหรับ classification/tool

Mode 2 — HPO (Optuna)

Request

{
  "mode": "hpo",
  "project_id": "<uuid>",
  "dataset_id": "<train_dataset_id>",
  "base_model": "unsloth/Llama-3.2-1B-Instruct-bnb-4bit",
  "training_name": "hpo-search-1",
  "hpo_config": {
    "n_trials": 6,
    "objective_metric": "eval_loss",
    "direction": "minimize",
    "sampler": "tpe",
    "pruner": "median",
    "timeout_seconds": 14400,
    "search_space": {
      "learning_rate": { "type": "float", "low": 1e-5, "high": 5e-4, "log": true },
      "lora_r": { "type": "categorical", "choices": [8, 16, 32] },
      "lora_alpha": { "type": "categorical", "choices": [16, 32, 64] },
      "num_train_epochs": { "type": "int", "low": 2, "high": 4 },
      "gradient_accumulation_steps": { "type": "categorical", "choices": [4, 8, 16] }
    },
    "fixed_config": {
      "per_device_train_batch_size": 2,
      "max_seq_length": 2048
    }
  }
}
HPO safety guard: ห้ามใส่ per_device_train_batch_size ใน search_space สำหรับ 3B base — service จะ reject 422.

Verify post-training

GET /api/v1/trainings/{training_id}              → status=completed, mlflow_run_id populate
GET /api/v1/models?training_job_id={training_id} → ควรได้ 1 artifact

Cancel (mid-training)

DELETE /api/v1/trainings/{training_id}
→ 202 { "training_id": "...", "status": "cancelled" }

Idempotent — เรียกซ้ำได้ ไม่ 500

เคสNote
