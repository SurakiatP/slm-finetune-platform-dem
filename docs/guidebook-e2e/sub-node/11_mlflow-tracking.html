11.1 Loss history (FE chart endpoint)

GET /api/v1/trainings/{training_id}/loss-history

Lightweight — return เฉพาะ train_loss + eval_loss series

{
  "training_id": "<uuid>",
  "mlflow_run_id": "<run_id>",
  "train_loss": [
    { "step": 0, "value": 4.78, "timestamp_ms": 1778398570184 },
    { "step": 4, "value": 1.05, "timestamp_ms": 1778398570500 }
  ],
  "eval_loss": [
    { "step": 0, "value": 3.96, "timestamp_ms": 1778398570198 },
    { "step": 4, "value": 1.42, "timestamp_ms": 1778398570600 }
  ]
}
BehaviorNote
Sort ordersorted by step ascending
Training ยังไม่เริ่มtrain_loss=[], eval_loss=[], mlflow_run_id=null (200)
MLflow down502 + "MLflow tracking server not reachable"

11.2 Full metrics + HPO summary

GET /api/v1/trainings/{training_id}/metrics

Manual mode response:

{
  "training_id": "<uuid>",
  "mlflow_run_id": "<run_id>",
  "metrics": {
    "train_loss":    [...],
    "eval_loss":     [...],
    "learning_rate": [...],
    "epoch":         [...],
    "grad_norm":     [...],
    "loss":          [...]
  },
  "hpo_children": null
}

HPO mode response — เพิ่ม hpo_children:

{
  "training_id": "<uuid>",
  "metrics": { ... },
  "hpo_children": [
    {
      "run_id": "37f0c88926...",
      "name": "trial-000",
      "final_eval_loss": 3.87,
      "params": { "learning_rate": "0.000115", "lora.r": "8" }
    },
    {
      "run_id": "8a5329ed43...",
      "name": "best",
      "final_eval_loss": 3.87,
      "params": {
        "best_params.learning_rate": "0.000115",
        "best_params.lora_r": "8",
        "best_metric_value": "3.87"
      }
    }
  ]
}
params value type = string เสมอ (MLflow stores params as strings). Frontend ต้อง parseFloat/parseInt ก่อนใช้ใน chart

11.3 Open in MLflow UI

GET /api/v1/trainings/{training_id}/mlflow-url
{
  "training_id": "<uuid>",
  "mlflow_run_id": "<run_id>",
  "mlflow_url": "http://mlflow:5000/#/experiments/1/runs/<run_id>"
}
Caveat: mlflow_url ใช้ internal hostname mlflow:5000 — frontend ต้อง substitute เป็น localhost:5000 (หรือ public hostname) ก่อน redirect

Direct MLflow UI access

เปิด browser ไปที่ http://<host>:5000 (ผ่าน port-forward) เพื่อดู:

  • experiment tree (project_id → trainings)
  • nested runs (HPO trials)
  • artifact tree (LoRA adapter, config, logs)
  • compare runs side-by-side

Verify checklist หลัง Node 6 จบ

เช็คคาดหวัง
loss-history.train_loss.length≈ steps_total
loss-history.eval_loss[last].valueลดลงจาก step แรก (ถ้าไม่ลด — รีวิว lr / epochs)
metrics.metrics keys~13 keys (train_loss, eval_loss, lr, epoch, grad_norm, ฯลฯ)
HPO: hpo_children.length= n_trials + 1 (best)
