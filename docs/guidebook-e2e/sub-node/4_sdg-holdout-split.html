Node 4 — SDG + Holdout Split (MINHASH)

POST ASYNC 202 /api/v1/datasets/generate
WS /ws/jobs/{job_id}

วัตถุประสงค์

Trigger Synthetic Data Generation แบบ with_seed (อ้าง dataset ที่ upload จาก Node 3a) + ทำ holdout split เพื่อ generate เพิ่มสำหรับใช้ evaluate (รัน MinHashLSH dedup ตลอดทาง).

Pipeline ภายใน worker

  1. Meta-prompting — LLM สร้าง diversity hints จาก task_description
  2. Generating — call OpenRouter (async batched, chat_batch) จนได้ num_samples + holdout_size rows
  3. Validating — Pydantic + per-task validators (closed-label, tool-name, JSON-decode)
  4. Deduplicating — MinHashLSH near-dup removal + seed-aware
  5. Judging — LLM-as-judge 1-5 (weighted 0.4/0.3/0.3) — reject score < 3
  6. Holdout split — stratified (cls / tool) หรือ random (qa) — สร้าง child Dataset
  7. Persisting — JSONL ขึ้น MinIO + DB rows update

Prerequisite

  • มี project_id + seed_dataset_id (จาก Node 3a) — ถ้ามาจาก Node 3b (description_only) ก็ข้าม seed_dataset_id ได้
ตัวอย่างด้านล่างใช้ domain เดียวกันกับ seed_data/ — task_description ต้องสอดคล้องกับเนื้อหา seed file ที่ upload ที่ Node 3a
กฎสำคัญสำหรับ with_seed: ห้ามใส่ classification_config หรือ tool_calling_config — schema มี extra="forbid" จะ 422 "Extra inputs are not permitted".
เหตุผล: labels / tool_definitions ถูก infer จาก seed dataset rows อัตโนมัติ — ส่งซ้ำไม่ได้

Subscribe WebSocket (real-time progress)

เปิดอีก tab Swagger ไม่ได้ — ใช้ browser console:

const ws = new WebSocket("ws://localhost:8000/ws/jobs/<job_id>");
ws.onmessage = (e) => {
  const msg = JSON.parse(e.data);
  console.log(msg.type, msg);
  if (msg.type === "completed" || msg.type === "failed") ws.close();
};

Events ที่จะเห็น

EventPhase ที่เป็นไปได้
sdg_progress × Nmeta_prompting → generating → validating → judging → dedup → persisting
completed (1 ครั้งสุดท้าย)มี result.holdout_dataset_id ถ้า holdout_size > 0
failederror_type + error message

เก็บค่าไว้ทั้ง 2:
  • train_dataset_id = dataset_id (parent) → ใช้ train ใน Node 6
  • holdout_dataset_id = result.holdout_dataset_id (child) → ใช้ evaluate ใน Node 9
